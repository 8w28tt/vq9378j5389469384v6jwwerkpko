# 🚀 Steam Level & Badge Master (Userscript)

Пользовательский скрипт для браузера, решающий главные боли прокачки уровня Steam: ручной подсчет карточек, поиск дешёвых сетов, зависшие ордеры на Торговой площадке и бесконечные анимации ковки значков.

---

## ⚡ Ключевые возможности

### 1. 📊 Умный калькулятор уровней (Level Roadmap)
* Введите текущий уровень и желаемый уровень (например, с 24 до 50).
* Скрипт мгновенно рассчитает:
  * Точное количество необходимого опыта (**XP**) по алгоритму Steam.
  * Сколько значков (сетов) нужно скрафтить.
  * **Реальную оценочную стоимость в вашей валюте** (₸ тенге, руб., $, € и т.д.), рассчитанную по сумме цен самых дешевых доступных сетов из базы прямо сейчас!
* Напомнит про Магазин очков Steam (сезонный значок даёт до 4 000 XP бесплатно).

### 2. 🏷️ Каталог самых дешёвых сетов (14 000+ игр)
* Прямо в интерфейсе страницы значков Steam (`/badges/`) отображается актуальный каталог всех сетов:
  * Поиск игр по названию.
  * Фильтр: **«Скрыть завершённые (уровень 5)»** — автоматически сверяется со значками вашего профиля.
  * Фильтр: **«Только 5 карт в сете»** (самые выгодные и быстрые).
  * Цены переведены в **валюту вашего аккаунта** по актуальному курсу.
* Действия в один клик:
  * Кнопка **«🔗 Открыть»** — переход к странице значка игры.
  * Кнопка **«🛒 Купить»** — моментально открывает окно проверки цен маркета и выставления ордеров прямо со страницы значков!

### 3. 🎯 Выбор целевого уровня конкретного значка (от 1 до 5)
* На странице значка любой игры (`/gamecards/{appid}/`) появляется селектор уровней: **1, 2, 3, 4, 5**.
* Скрипт считывает ваш текущий уровень и количество уже имеющихся дубликатов карт.
* Рассчитывает дефицит без лишних покупок.

### 4. 🔍 Личная перепроверка реальных цен (Live Review Modal)
* Никаких покупок «вслепую».
* Прямой опрос официального API маркета Steam для каждой недостающей карты.
* Интерактивная таблица перед покупкой:
  * Название карты и сколько штук нужно.
  * Минимальная цена сейчас.
  * Цена гарантированного выкупа (Instant-Fill).
  * Общая стоимость позиции.
  * Чекбоксы: можно снять галочку с любой отдельной карты.

### 5. ⚡ Решение проблемы «купилось 2 из 5» (Instant-Fill)
* **Режим Instant-Fill**: скрипт анализирует стакан предложений на ТП и ставит ордер по цене **$N$-го лота**.
* Все $N$ карт выкупаются **мгновенно за 1 секунду**, а ордер не зависает!
* Также доступен режим **«Минимальная цена (экономный)»**.

### 6. 🚀 Turbo Crafter (Мгновенная ковка значков)
* Мгновенный крафт через прямые AJAX-запросы Steam без просмотра 15-секундных анимаций:
  * На странице конкретной игры в 1 клик.
  * Массовый крафт **всех готовых значков** на главной странице `/badges/` пачкой за пару секунд.

## 🛠 Установка (за 1 минуту)

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) (или Violentmonkey) в ваш браузер.
2. Откройте панель расширения → **«Создать новый скрипт»**.
3. Скопируйте всё содержимое файла [`steam-level-master.user.js`](file:///Users/oviot/Documents/Antigravity/steam-level-master.user.js) и вставьте его вместо шаблона.
4. Нажмите **Файл -> Сохранить** (`Ctrl + S` / `Cmd + S`).

---

## 🎮 Как пользоваться

1. Откройте в браузере страницу **Значки** (`https://steamcommunity.com/my/badges/`).
2. Вверху появится панель **Steam Level Master** с 3 вкладками:
   * **📊 Калькулятор уровня**: введите желаемый уровень и узнайте бюджет.
   * **🏷️ Каталог дешёвых сетов**: выбирайте самые выгодные значки и покупайте карты в 1 клик.
   * **⚡ Быстрый крафт**: крафтите все готовые значки разом.
3. При открытии значка любой игры (`/gamecards/{appid}/`) пользуйтесь конфигуратором уровней 1–5 и Instant-Fill закупкой!
