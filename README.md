# 🚀 Steam Level & Badge Master (Userscript)

Пользовательский скрипт для браузера, решающий главные боли прокачки уровня Steam: ручной подсчет карточек, поиск дешёвых сетов, бесконечные запросы 2FA-подтверждений на телефоне и долгие анимации ковки значков.

---

## ⚡ Ключевые возможности

### 1. 🛒 Официальный Multi-Buy без подтверждений на телефоне (0 2FA)
* **Больше никаких подтверждений в Steam Mobile Guard!** 
* Одиночные запросы к API часто блокируются эвристиками антифрода Steam и требуют подтверждать каждый ордер в приложении на телефоне.
* Скрипт использует официальный механизм **Steam Multi-Buy** (`/market/multibuy`):
  * Все недостающие карты для нужного уровня значка собираются в единую транзакцию.
  * Страница Multi-Buy полностью автоматизирована: скрипт сам принимает Соглашение подписчика (SSA), выставляет нужное количество каждой карты (для уровней 1–5), размещает заказ в 1 клик и возвращает на страницу значка.
  * **0 подтверждений на телефоне** — покупка проходит гладко и сразу.

### 2. 🏷️ Каталог самых дешёвых сетов (14 000+ игр)
* Прямо в интерфейсе страницы значков Steam (`/badges/`) отображается актуальный каталог всех сетов:
  * Поиск игр по названию.
  * Фильтр: **«Скрыть завершённые (уровень 5)»** — автоматически сверяется со значками вашего профиля.
  * Фильтр: **«Только 5 карт в сете»** (самые выгодные и быстрые).
  * Цены переведены в **валюту вашего аккаунта** (₸ тенге, руб., $, € и т.д.) по актуальному курсу.
* Действия в один клик:
  * Кнопка **«🔗 Открыть»** — переход к странице значка игры.
  * Кнопка **«🛒 Multi-Buy»** — моментально открывает Multi-Buy для всей игры со страницы значков!

### 3. 🎯 Умный конфигуратор значка (уровни 1–5)
* На странице значка любой игры (`/gamecards/{appid}/`) появляется селектор уровней: **1, 2, 3, 4, 5**.
* Скрипт распознает ваш текущий уровень значка (по порядковым суффиксам вроде `4-й уровень` или `400 ед. опыта`).
* Точно рассчитывает дефицит карт с учетом уже имеющихся дубликатов.
* Главная кнопка: **«🛒 Купить через Multi-Buy (без подтверждений на телефоне)»**.

### 4. 🔍 Личная перепроверка реальных цен со стаканом (Live Review Modal)
* Для тех, кто хочет контролировать каждую копейку перед покупкой:
  * Прямой опрос официального API маркета Steam для каждой недостающей карты.
  * Таблица с минимальными ценами, ценами Instant-Fill и выборочными чекбоксами.
  * Возможность отправить выбранные позиции сразу в Multi-Buy или выставить через ордеры API.

### 5. 🚀 Turbo Crafter (Мгновенная ковка значков)
* Мгновенный крафт через прямые запросы без ожидания анимаций:
  * На странице конкретной игры в 1 клик.
  * Массовый крафт **всех готовых значков** на главной странице `/badges/` пачкой за пару секунд.

## 🛠 Установка (за 1 минуту)

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) (или Violentmonkey) в ваш браузер.
2. Откройте панель расширения → **«Создать новый скрипт»**.
3. Скопируйте всё содержимое файла [`steam-level-master.user.js`](file:///Users/oviot/Documents/Antigravity/steam-level-master.user.js) и вставьте его вместо шаблона.
4. Нажмите **Файл -> Сохранить** (`Ctrl + S` / `Cmd + S`).

---

## 🎮 Как пользоваться

1. Откройте в браузере страницу **Значки** (`https://steamcommunity.com/my/badges/`).
2. Вверху появится панель **Steam Level Master** с 2 вкладками:
   * **🏷️ Каталог дешёвых сетов**: выбирайте самые выгодные значки и покупайте карты в 1 клик через Multi-Buy.
   * **⚡ Быстрый крафт**: крафтите все готовые значки аккаунта разом без ожидания анимаций.
3. При открытии значка любой игры (`/gamecards/{appid}/`) выбирайте нужный уровень (1–5) и нажимайте **«🛒 Купить через Multi-Buy»** — заказ сформируется автоматически без подтверждений на телефоне!
